# `@benchguard/cli`

This package installs the native BenchGuard performance-regression CLI for
supported x86-64 Windows and Linux systems. It requires Node.js 18 or newer
only for installation and dispatch; measurement runs in the Rust binary.

```console
npm install --global @benchguard/cli
benchguard help
```

See the project README and JSON documentation in the source repository for the
complete quick start, metric scopes, and exit-code contract.
